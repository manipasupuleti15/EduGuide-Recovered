# EduGuide APK Recovery

Recovered files from the EduGuide Android APK.

## Original web app URL
https://careercompasseduguide.lovable.app

## Important
The APK is an AppsGeyser WebView wrapper. The original Lovable HTML/CSS/JavaScript source was not embedded in the APK, so this repository is a recovery archive rather than the original source repository.

See `RECOVERY_REPORT.md` for details.
